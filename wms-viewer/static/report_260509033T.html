⚠️ UOMKEY='R' 오분류 — 핵심 원인

_is_roll_it() 함수는 UOMKEY=='R'이면 무조건 롤(Roll)로 판별합니다.
그러나 이 6건의 UOMKEY='R'은 Ream(속) 단위의 판지 포장을 의미합니다. SKUKEY 접두어 F(=평판지)임에도 롤 배차 경로로 진입하여 INCH12_GE300=6 (롤수 MAX_COUNT) 기준으로 10톤이 선정되었습니다.

ℹ️ 왜 1.4톤이 아닌 10톤인가?

중량 기준만 보면 945.83kg은 1.4톤(1,500kg, 첨부율 63%)에 적재 가능합니다.

_best_fit_car()는 롤수 제약을 만족하는 차종 중 첨부율 최고를 선택하므로, 6롤을 수용 가능한 가장 작은 차종인 10톤(INCH12_GE300=6)이 선택됩니다.

5. 주의사항 상세 분석 (4건)

제약 위반 아님 — 알고리즘 설계 이슈

⚠️ Issue #1 — UOMKEY='R' 롤 오분류 (핵심)

관련 제약: ROLL_UNIT(34,36), ROLL_INCH_MIX(47)

_is_roll_it(it) 함수 내 if uom == 'R': return True 조건으로 인해
이 6건의 판지 Ream(속) 포장품이 모두 원지 롤(Roll)로 분류됩니다.

결과: INCH12/INCH3 롤수 체크, ROLL_INTEGER_ONLY, ROLL_MIN_QTY 등 원지 전용 제약이 판지에 적용됩니다.

수정 권고: _is_roll_it()에 SKUKEY[0]=='H' 추가 조건 적용
→ if uom == 'R' and skukey[0] == 'H': return True

⚠️ Issue #2 — ROLL_INTEGER_ONLY 위반 가능성 (ID=34)

ROLL_INTEGER_ONLY=Y는 원지 롤의 정수 단위 강제 제약입니다.
SEQ2(1.6R), SEQ5(0.8R), SEQ6(0.4R)은 비정수 수량이나,
이 품목들은 판지 Ream 포장이므로 해당 제약 대상이 아닙니다.
UOMKEY='R' 오분류로 인해 잘못 적용될 수 있는 이슈입니다.

⚠️ Issue #3 — ROLL_MIN_QTY 위반 가능성 (ID=36)

ROLL_MIN_QTY≥1은 원지 최소 1롤 배차 보장 제약입니다.
0.4R(SEQ6), 0.8R(SEQ5)는 1미만이나, 이 역시 판지 Ream 수량이므로
원지 기준이 적용되어서는 안 됩니다.

⚠️ Issue #4 — ROLL_REF_3INCH_GE300 인치 기준 불일치 (ID=47)

SKUKEY[1]='3' → 3인치 코어인데, 알고리즘 API 노트는 "[12인치 롤수체크] GE300 6롤 / MAX_COUNT=6"으로 12인치 기준(INCH12_GE300)을 적용했습니다.

3인치 기준 ROLL_REF_3INCH_GE300=3,5,10,12,14,14,15에서 10톤 MAX는 14롤이므로, 3인치 기준으로는 10톤에 14속까지 가능합니다.
현 알고리즘이 인치 판별 없이 INCH12_GE300을 기본값으로 사용하는지 확인이 필요합니다.

ℹ️ BOARD_BULK_INTEGER_ONLY 잠재 이슈 (ID=55)

BOARD_BULK_INTEGER_ONLY=Y는 판지 벌크 1PLT 단위 강제 제약입니다.
1.6R, 0.8R, 0.4R의 비정수 수량은 이 제약과 충돌할 수 있으나,
BOARD_INNER_SPLIT_ALLOW=Y에 의해 속 단위 분할이 허용되므로 실질적 위반은 아닙니다.

또는: if uom == 'R' and skukey and skukey[0] == 'H': return True

효과: 판지 Ream이 롤 경로에서 분리 → 중량 기반 차종 선정 → 1.4톤 또는 2톤 선정 → 적재율 60%+ 달성

🔧 권고 #2 — MIN_FILL_RATIO 설정값 검토

현재 MIN_FILL_RATIO=0% (제한없음)이므로 9.5% 적재도 허용됩니다.
판지 전용 최소 적재율(예: 20~30%)을 설정하면 극저 적재율 배차 자동 차단이 가능합니다.

🔧 권고 #3 — SKUMA 마스터 등록

6개 품목 모두 SKUMA 테이블에 미등록 상태입니다.
SKUKEY 파싱에 의존하는 현재 방식보다 SKUMA 등록으로 CBM/치수 계산의 정확도를 높이는 것을 권고합니다.
